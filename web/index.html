Reconcile any set of documents.

Add your files, choose which ones should agree, and anyrecon finds the references they share and matches them line by line. Anything that doesn't match comes with a reason.

How it works

No setup and no account.

1

Add your documents

Processor exports, ledgers, bank statements, settlement reports. CSV, Excel, JSON or PDF. Multi-tab workbooks are fine.

2

Check the connections

anyrecon proposes how the files link, even through prefixes, missing zeros or references buried in bank narrations, and shows how many rows each link matches, with examples.

3

Confirm or change

Accept the proposal or pick a different match. Matching then runs on fixed rules; a consistent fee such as MDR is spotted and applied.

4

Review the breaks

Missing items, amount differences, timing, duplicates and likely typos, each with a reason. Download the Excel report and an audit trail.

Your data

Built for card and bank data. Full detail in the guide.

Where it runs
In this browser tab. Files are read here and never uploaded.
Card numbers
Masked to the first six and last four digits on load. Security codes and PIN data are removed.
What is kept
Nothing. Close the tab or clear the session and it's gone.
How matching works
Fixed rules you can see, not guesses. Every match records the rule that made it.

Run it on your computer

For large files, scanned documents or working offline. Same tool, same results, and your files stay on your computer.

Download for WindowsZIP, about 1 MB
  1. Download and unzip it (right-click → Extract All).
  2. In the anyrecon-main folder, double-click Start anyrecon (Windows).bat. If Windows says it protected your PC, click More info → Run anyway.
  3. No Python yet? The download page opens: install it, ticking Add python.exe to PATH (no administrator rights needed), then double-click the file again.
  4. The first run sets itself up in 2–5 minutes, then anyrecon opens in your browser.
Download for MacZIP, about 1 MB
  1. Download it; it unzips into an anyrecon-main folder.
  2. Right-click Start anyrecon (Mac).command → Open → Open. The right-click is needed the first time only.
  3. No Python yet? The download page opens: install it (it may ask for your Mac password), then repeat step 2.
  4. The first run sets itself up in 2–5 minutes, then anyrecon opens in your browser.
Download for LinuxZIP, about 1 MB
  1. Download and unzip it.
  2. In a terminal, in the anyrecon-main folder: bash start-anyrecon-linux.sh
  3. Needs Python 3.10+ with venv (sudo apt install python3-venv on Ubuntu).
  4. The first run sets itself up in 2–5 minutes, then anyrecon opens in your browser.
Installs only inside its own folder: delete the folder to remove it. The first run downloads its components from pypi.org; after that it works offline. Can't install anything? This page needs nothing installed. Help and troubleshooting.
